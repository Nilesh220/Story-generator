# 📸 Instagram Story Views & Insights Generator

A pixel-perfect, interactive web application to generate 100% authentic Instagram Story Views & Insights screenshots for iOS and Android.

## ✨ Features
- **1:1 iOS Authenticity**: Exact fonts (`SF Pro`), icons, geometry, status bar, and layouts.
- **Interactive Controls**:
  - **Status Bar**: Custom time, battery level slider, battery % text toggle (show/hide), signal strength, network type (WiFi / 5G / LTE), and silent mode bell (`🔕`).
  - **Story Carousel**: Custom poster upload, direct viewers overlay count, and camera card.
  - **Overview & Donut Chart**: Dynamic proportional followers (magenta) vs non-followers (indigo) donut arc rendering.
  - **Viewers List**: Add, delete, and randomize viewers with verified badges, gradient story rings, close-friends rings, and reaction emojis.
  - **Light Mode & Dark Mode**: Full native support for both themes.
  - **Device Models**: iPhone 14/13, iPhone 16/15 Pro, iPhone 15 Pro Max, Galaxy S24, and flat rectangular mode.
- **Presets Included**:
  - 92 Views (Light)
  - 68 Views (Light)
  - 44 Views (Light)
  - 625 Views (Dark Mode)
  - 767 Views (479 Viewers)
  - 10K Viral Views
- **Exporting**:
  - 3x Ultra-sharp Retina PNG download.
  - Instant copy to clipboard.

## 🚀 Getting Started
Open `index.html` in any modern web browser or serve locally:
```bash
python -m http.server 8080
```
Then navigate to `http://localhost:8080`.
